RRA Engine: From TPU Discovery to C++ Embodiment
1. The TPU Discovery Phase (scripts/colab_tpu_*)
The core logic of the RRA engine was derived through massive-scale simulations on Google Cloud TPUs (XLA). We optimized a Universal Plasticity Law represented by a 369-parameter MLP that bridges the gap between Spiking Neural Networks (SNN) and Reinforcement Learning.

Key Discoveries:
Temporal Credit Assignment: The TPU discovered that a decay constant of τ = 11.0ms for molecular eligibility traces is optimal for aligning axonal delays with dopamine delivery.
Plasticity Rule: $$\Delta W = MLP(\text{trace_v_pre}, \text{trace_v_post}, \text{trace_Ca}, \text{Reward})$$ This rule replaces standard Hebbian or STDP rules with a learned, non-linear function that handles asynchronous rewards.
Polychronization: Axonal delays are not just noise; they are structural memory. The TPU simulations showed that specific delay patterns ($1\text{ms}$ to $15\text{ms}$) create "polychronous groups" that store complex temporal sequences.
2. C++ backend (nn/brain_tree/)
We moved from Python/PyTorch to native C++ to achieve the performance required for real-time embodiment on local hardware (i5-1035g1).

Technical Specifications:
Event-Driven Architecture: Instead of fixed time-steps ($O(N)$), we use a Priority Queue ($O(\log E)$) where $E$ is the number of events. This allows simulating sparse spiking activity with microsecond precision.
Memory Efficiency: The CorticalTissue uses a flat memory layout where possible, ensuring cache-friendly access during the "Dopamine Waves" that broadcast rewards to all synapses.
C++20 Integration: Utilizing modern C++ features for performance and safety (std::ranges, atomic state sharing).
3. Real-Time Embodiment (tests/car_visual.cpp)
The "Car Testbench" is the first real-time validation of the TPU-derived laws.

Simulation Dynamics:
Sensory Input: 5 Raycast sensors (proximity to walls) mapped to input neuron firing frequencies.
Motor Output: 4 Motor neurons (Left, Right, Accel, Brake) where spike counts determine physical forces.
Dopamine Loop: Positive rewards for distance/speed, negative for crashes/stagnation.
Evolutionary Loop: A population of 6 agents competes. The best brain is serialized to .safetensors using the HuggingFace format, ensuring persistence.
